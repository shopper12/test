# 해상풍력 벤치마킹 출장 대시보드 2026

Google Maps 공유 목록을 업무장소의 유일한 기준으로 삼은 두 가지 출장안 비교·협업 대시보드입니다.

- 일정: 2026-09-02 저녁 출발 ~ 2026-09-12
- 안 A: 유럽 먼저 → AWTEC → 대만 종료 → 타이중에서 인천 직항
- 안 B: 대만 먼저 약 3일 → AWTEC 제외 → 함부르크·덴마크·오슬로·네덜란드 → 인천
- 업무장소: 공유 Google Maps의 풍력 관련 장소 9곳만 사용. 안 A에만 AWTEC 추가
- 호스팅: GitHub Pages
- 로그인 없는 익명 공동편집: Supabase Free Anonymous Sign-ins + RLS
- 지도: Leaflet + OpenStreetMap + OSRM 실제 육상경로
- 항공가격: GitHub Actions가 Google Flights를 성인 4명·일반석 조건으로 매시간 자동조회

## 대시보드

- 배포 주소: https://shopper12.github.io/test/
- 저장소: https://github.com/shopper12/test

상단의 두 일정안 탭으로 즉시 전환할 수 있습니다. 안 A는 AWTEC가 필수일 때, 안 B는 AWTEC 없이 관광·업무 균형을 우선할 때 사용합니다. 이메일·비밀번호 로그인 화면은 제거했고, 선택한 안을 안전 적용하면 Supabase 익명 세션으로 공동편집합니다.

- 각 일정안은 독립된 일정·지도·항공·숙박·예산을 표시합니다.
- 일정 카드를 드래그하면 순서가 공동 저장됩니다.
- Day 날짜를 옮기면 이후 일정과 항공·숙박 검색 날짜가 연쇄 변경됩니다.
- 지도는 Day 변경을 즉시 반영하고, 자동차 구간은 OSRM 실제 도로 형상을 불러옵니다.
- 항공은 노선 절대최저가와 일정에 맞춘 채택편 가격을 4인 총액·1인 금액으로 나눠 표시합니다.
- 항공 행의 Google Flights 버튼은 자동조회에 사용한 날짜·공항·인원 조건의 실제 결과로 연결합니다. Skyscanner 교차비교 링크도 제공합니다.
- 숙박은 Booking.com에 날짜·성인 4명·객실 2실 조건을 넣은 결과로 연결합니다.
- 자동 운임은 `flight-prices.json`에 조회시각과 유효시각을 기록합니다. 위탁수하물·좌석·결제수수료와 재고 변동은 최종 예약화면이 기준입니다.

안전 적용 시 기존 클라우드 데이터는 JSON으로 먼저 내려받고, 팀 메모를 보존한 채 일정·항공·숙박·지도·예산 테이블만 새 기준안으로 교체합니다.

`확정·검증` 탭에서 허용 업무장소 수, 삭제한 기존 업무장소, 발권·기관 회신 미확정 수, 공식 링크와 최종 운임 조회시각을 확인할 수 있습니다.

## 항공가격 자동갱신

`.github/workflows/update-flight-prices.yml`이 매시간 `scripts/update_flight_prices.py`를 실행합니다. 두 일정의 핵심 9개 구간과 직항·홍콩 경유 비교 3개 구간, 총 12개를 성인 4명 기준으로 조회합니다.

- `lowest`: 해당 날짜·노선·환승조건의 절대최저가
- `selected`: 대시보드 일정의 출발시각에 맞는 채택편 가격

개별 검색이 실패하면 마지막 성공값을 `stale`로 유지하며, 화면은 이를 최신 가격으로 표시하지 않습니다.

2026-07-24 조회에서는 유럽 선행안의 ICN→CPH 두바이 환승이 직항보다 4인 약 1,082만원 저렴했고, RMQ→ICN 직항은 홍콩 경유보다 약 28만원 저렴하면서 약 11시간 30분 빨랐습니다. 이 숫자는 매시간 갱신됩니다.

## 배포

GitHub Actions의 `Deploy GitHub Pages` 워크플로로 자동 배포합니다. 배포 주소가 404이면 저장소 **Settings → Pages → Source → GitHub Actions**를 최초 한 번 선택하십시오.
