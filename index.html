해상풍력 벤치마킹 출장 2026

GitHub Pages 무료 호스팅 · 로그인 없는 Supabase 익명 공동편집 · Leaflet/OpenStreetMap·OSRM 육상경로
항공 금액은 GitHub Actions가 Google Flights를 매시간 조회한 성인 4명 일반석 스냅샷입니다.
날씨는 대만 CWA·네덜란드 KNMI·독일 DWD·덴마크 DMI·한국 KMA의 공식 예보만 사용하며, 예보 발표 전에는 평년값이나 과거자료를 표시하지 않습니다.
장소 사진은 호텔·식당·기업·관광지의 공식 웹사이트가 공개한 대표 이미지 메타데이터만 사용하고 Wikimedia/스톡 사진으로 대체하지 않습니다.
지도는 자동차 OSRM 도로선과 유럽 대중교통 Transitous/MOTIS GTFS 경로를 Leaflet 화면 안에 직접 표시합니다. 대만 THSR/Airport MRT는 공개 라우팅 데이터가 없는 구간은 일정 지점 연결선으로 표시합니다.
각 서비스의 최종 예약·운행·기상 조건은 카드의 공식 원문 및 결제 링크에서 다시 확인하십시오. 공개 저장소 기반이므로 여권번호, 연락처, 계약자료 등 비공개 정보는 입력하지 마십시오.
